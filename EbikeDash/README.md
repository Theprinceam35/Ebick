# مشروع عدّاد البسكليت (أندرويد)

## البناء
1. ثبّت Android Studio (آخر إصدار) على الحاسوب.
2. File ثم Open، واختر مجلد EbikeDash هذا، وانتظر انتهاء Gradle Sync (يحتاج إنترنت).
3. وصّل الهاتف بكابل مع تفعيل USB debugging ثم Run ▶،
   أو Build ثم Build APK(s). الملف الناتج:
   app/build/outputs/apk/debug/app-debug.apk

## الاستخدام
- اضغط «اتصال بالـBMS»، اسمح بالأذونات، ثم اختر جهاز JK من القائمة (أغلق تطبيق JK BMS أولاً).
- اضغط «ابدأ الرحلة». تستمر القراءة والتسجيل والشاشة مغلقة، وتظهر إشعار «إيقاف».
- أول تشغيل يحتاج إنترنت لتحميل مكتبة الخريطة وصورها.

## البنية
- TrackService.kt: خدمة أمامية تقرأ GPS وبلوتوث JK وتخزّن الأحداث أثناء إطفاء الشاشة.
- Model.kt: الحالة والحسابات وقراءة إطار JK وحفظ الرحلات.
- MainActivity.kt و Ui.kt: واجهة أصلية بالكامل (Kotlin) مع خريطة osmdroid.

## البناء السحابي (بدون Android Studio)
ارفع محتويات هذا المجلد كلها (مع .github) إلى مستودع GitHub، ثم من تبويب Actions حمّل app-debug.
